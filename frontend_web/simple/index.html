"Remember: to add fractions, you first need a common denominator. Try rewriting both fractions with the same bottom number before adding."
Session 3 · after 2 prior misses on this exact gap

"This is the same common-denominator step that tripped you up last time — you added the denominators directly. This time, try listing multiples of 2 and 3 first: which one shows up in both lists?"
